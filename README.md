# 國文閱讀理解密室逃脫網頁模板 (Escape Room Template)

這是一個通用的「國文閱讀理解密室逃脫」網頁模板。只要提供您的課文教材，AI 助手就可以利用本專案的模板與 Skill 指南，自動產生出專屬的線上互動式閱讀密室逃脫遊戲！

## 📦 專案結構說明

- `index.html`：通用密室逃脫網頁引擎（包含雲朵背景動畫、隨機抽題打亂、學生姓名輸入、自動獲取證書等）。
- `escape_room_generator_skill.md`：給 AI 讀取的自動產生網頁 Skill 指南。
- `escape_room_post_skill.md`：給 AI 讀取的自動撰寫臉書粉專發文 Skill 指南。
- `assets/audio/`：預設的背景音樂與過關音效檔案。
- `assets/img/character.png`：右下角緩慢搖擺的預設人物去背頭像（可自行替換為課文相關人物）。

---

## 🚀 如何使用它來建立新課文遊戲？

1. **複製模板庫**：Fork 本儲存庫，或直接複製此資料夾下的所有內容到您新課文的備課資料夾下。
2. **啟動 AI 助手**：在對話中直接附上新課文（如 `課文.txt`）或您的自訂題庫。
3. **下達指令**：對 AI 說：
   > *「請讀取 `escape_room_generator_skill.md`，幫我為〈新課文名稱〉建立密室逃脫網頁。」*
4. **互動確認**：AI 就會自動出題，並跟您確認視覺主題色彩、去背頭像人物與 GitHub Pages 線上網址！

---

## 🔊 使用素材

- 網頁結構：純 HTML5 + CSS3 + Vanilla JS（無任何外部依賴框架，點開即玩，支援手機與桌機 RWD 響應式）。
- 音效版權：內含背景音樂與獲勝音效，支援音效開關。
